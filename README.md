AWS Outposts is a family of fully managed solutions delivering AWS infrastructure and services to virtually any on-premises or edge location for a truly consistent hybrid experience. It allows you to extend AWS infrastructure, AWS services, APIs, and tools to virtually any data center, co-location space, or on-premises facility.

**Areas:** AWS · Edge Computing · Hybrid Cloud · Infrastructure · On-Premises

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Amazon Outposts: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
